# Apna Bazaar — Vercel-ready

## Deploy
Import this GitHub repository into Vercel.
- Framework Preset: Other
- Root Directory: `./`
- Build Command: leave empty
- Output Directory: leave empty

The `public` folder is served as the website and `api` contains Vercel serverless functions.

## Important
Orders are NOT permanently stored yet. For production, connect `/api/orders` to MongoDB, Supabase, or PostgreSQL and add an admin dashboard/authentication.
